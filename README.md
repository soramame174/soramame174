## 制作物 (Featured Project)
自分が開発したフリー音楽WEBアプリです。
### [MelodyNotes (メロディノ)](https://github.com/soramame174/vantan1)
- 概要: 音楽クリエイター同士がフリーの楽曲を登録・検索・共有できるプラットフォームです。ファイル機能で管理がしやすくなり、クリエイターの創作活動を支援するために作成いたしました。
- 詳細は上記リポジトリのREADMEをご覧ください。
- 特徴:
  - 直感的な楽曲管理: ファイル管理機能により、お気に入りの楽曲を整理しやすく、創作活動に集中できる環境を提供します。
  - 楽曲の検索・探索: アーティスト名やジャンルだけでなく、特定のキーワードで求める楽曲を即座に発見可能です。
  - リクエスト機能: 楽曲を探す側と提供する側のニーズをマッチングさせることで、単なるBGM共有に留まらない、次なる創作のヒントが生まれる場を提供します。
  - プレイリスト共有: 自分が作成したプレイリストを他ユーザーと共有し、オススメを紹介することで、クリエイター同士の交流を促進します。

自分が開発した従業員勤怠管理・生産性向上WEBアプリです。
### [勤怠管理・業務効率化システム](https://github.com/soramame174/attendance_system)
- 概要: 複数のITベンチャー企業での利用を想定した、従業員の勤怠管理業務の効率化と生産性向上を支援する統合管理プラットフォームです。

- 管理者向け機能:
  - 勤怠状況のリアルタイム監視と詳細グラフ生成（月別労働時間・出勤日数）。
  - 社員情報の管理（登録・編集・削除）およびセキュリティを考慮した専用コード発行機能。

- 従業員向け機能:
  - ToDoリストによるタスク管理と重要度設定。
  - チーム連携を強化する共有カレンダー機能（日数を跨いだ予定登録に対応）。
- 詳細は上記リポジトリのREADMEをご覧ください。
- 特徴:既存の管理ツールにおける「操作の複雑さ」や「フォロー不足」という課題を解決し、直感的なUIで管理者の負担を大幅に削減します。

チームで開発した運動促進WEBアプリです。
### [習慣樹 -Habitree- 🌱（完成版）](https://github.com/soramame174/Team-14_Django)
- 概要: Google Fitの歩数データと連動し、ユーザーが日々の健康習慣を継続することで「習慣の樹」を育てていく、ゲーミフィケーションを取り入れたヘルスケア習慣化WEBアプリケーションです。
- 背景と実績: 元々はハッカソンで複数人のチームで開発していたプロトタイプでしたが、イベント終了後にリーダーである自分が単独でプロジェクトを引き継ぎ、全面的なリファクタリングを敢行。コードの全量レビュー、フロント・バックエンドの厳密な同期、セキュリティ強化を行い、動作する商用レベルのプロダクトとして完成させました。
- 詳細は上記リポジトリのREADMEをご覧ください。
- 特徴:
  - Google Fit API 連携: ユーザーのリアルタイムな歩数データを自動取得・同期するロジックを実装（※Google APIのセキュリティ仕様上、OAuth認証は本番環境環境へのデプロイ後に有効化されますが、バックエンドの連携ロジック・データ処理は全量実装済みです）。
  - マスタータスクと通常タスクの違い: 管理者がタスクを作成し、そこから一般ユーザーがコピーする形になってるので管理者が消すまでタスクが消えることはありません。
